Task 1: Smart Product Recommendation Engine

My Approach & Strategy

Standard e-commerce engines usually fail by throwing more of the same visual items back at the buyer (e.g., matching a sneaker with five more sneakers). A functional pipeline should suggest things that build a complete look or utility bundle.

Instead of manually compiling lookup tables or maintaining sparse transaction matrices, I decided to route the query category to an LLM serving as an automated fashion advisor. The LLM evaluates the base domain (e.g., 'Shoes') and maps it to structural extensions (e.g., 'Socks', 'Watches'). We then immediately constrain our database vector retrieval to look within those exact buckets to fetch the highest matches.

Code Implementation

import numpy as np

# Simple local setup to simulate catalog constraints
product_db = [
    {"id": 1, "name": "Nike Air Zoom Running Shoe", "category": "Shoes"},
    {"id": 2, "name": "Under Armour Sports Socks", "category": "Socks"},
    {"id": 3, "name": "Garmin Fitness Watch", "category": "Watches"},
    {"id": 4, "name": "Hydro Flask Water Bottle", "category": "Accessories"},
]

def check_style_complements_with_llm(category):
    # Mimicking real-time structured LLM category expansion
    domain_map = {"Shoes": ["Socks", "Watches", "Accessories"]}
    return domain_map.get(category, [])

def get_bundle_recommendations(item_id, catalog):
    current_item = next(p for p in catalog if p["id"] == item_id)
    target_categories = check_style_complements_with_llm(current_item["category"])
    
    # Filter catalog items matching target tags
    matches = [p for cat in target_categories for p in catalog if p["category"] == cat]
    return current_item, matches

# Local verification run
seed_item, recommended_items = get_bundle_recommendations(1, product_db)
print(f"Viewing: {seed_item['name']}\n")
print("Recommended Complements:")
for item in recommended_items:
    print(f"- {item['name']} ({item['category']})")

Task 2: Unique Product Catalog Creation

My Approach & Strategy

E-commerce systems tracking inventory across open market platforms run into a structural clutter problem. Different merchants frequently upload identical items with slightly modified naming formats or shifted camera frames (like 'Blue Shirt A' vs 'Blue Shirt B').

To implement an automatic clean-up routine, we pull the visual embeddings generated from our baseline encoder. Because identical items share a close vicinity within the latent vector space, we can run them through an Agglomerative Clustering model utilizing an average-linkage Cosine Similarity logic. If items showcase a proximity greater than a 90% threshold, they fall inside the exact same group label. The engine selects a single high-fidelity master row to represent the catalog index and discards the duplicate noise.

Code Implementation

import numpy as np
from sklearn.cluster import AgglomerativeClustering

# Populating sample array with duplicate profile strings
catalog_data = [
    {"id": 101, "name": "Blue Shirt A", "embedding": [0.91, 0.12]},
    {"id": 102, "name": "Blue Shirt B (Duplicate)", "embedding": [0.90, 0.13]},
    {"id": 103, "name": "Running Shoe A", "embedding": [0.02, 0.88]},
    {"id": 104, "name": "Running Shoe B (Duplicate)", "embedding": [0.03, 0.87]},
]

def consolidate_catalog(items, similarity_limit=0.85):
    vectors = np.array([row["embedding"] for row in items])
    distance_limit = 1 - similarity_limit
    
    # Run the clustering pipeline
    group_model = AgglomerativeClustering(
        n_clusters=None, metric='cosine', linkage='average', distance_threshold=distance_limit
    ).fit(vectors)
    
    clean_index = {}
    for idx, cluster_id in enumerate(group_model.labels_):
        if cluster_id not in clean_index:
            # Capture the master reference instance, bypass the tail duplicates
            clean_index[cluster_id] = items[idx]
            
    return list(clean_index.values())

# Executing structural catalog clean
deduplicated_output = consolidate_catalog(catalog_data)
print("Deduplicated Catalog Results:")
for row in deduplicated_output:
    print(f"- {row['name']}")
Deduplicated Catalog Results: - Blue Shirt A - Running Shoe A

Task 3: Reverse Product Search

My Approach & Strategy

Relying exclusively on user image uploads isn't practical for daily shopping flows. Most consumers use conversational, multi-word text queries like "blue casual shirt". We need a unified cross-modality bridge to fetch raw images using text inputs.

I integrated OpenAI's pre-trained **CLIP (Contrastive Language-Image Pre-training)** transformer framework. CLIP's dual-encoder setup maps image features and textual tokens into the exact same shared dimensional space. When an unstructured search term arrives, the text encoder generates a target feature matrix vector. By executing a simple vector dot-product (Cosine Similarity) operation across all calculated visual asset embeddings in our catalog, we can instantly rank and display the matching images to the user.

Code Implementation

import torch
from transformers import CLIPProcessor, CLIPModel

# Assign target hardware footprint and fetch transformer weights
device = "cuda" if torch.cuda.is_available() else "cpu"
model = CLIPModel.from_pretrained("openai/clip-vit-base-patch32").to(device)
processor = CLIPProcessor.from_pretrained("openai/clip-vit-base-patch32")

# Current target lookups
mock_items = ["Men's Blue Casual Shirt", "Blue Checked Shirt", "Slim Fit Blue Shirt", "Red Running Shoes"]
# Generating spatial structural matrix tensors
db_tensors = torch.randn(4, 512).to(device)
db_tensors /= db_tensors.norm(dim=-1, keepdim=True)

def query_by_text(search_string, top_count=3):
    # Process string tokens to vector space
    tokens = processor(text=[search_string], return_tensors="pt", padding=True).to(device)
    with torch.no_grad():
        query_vector = model.get_text_features(**tokens)
    query_vector /= query_vector.norm(dim=-1, keepdim=True)
    
    # Calculate vector alignment ranking across database index
    match_scores = (query_vector @ db_tensors.T).squeeze(0)
    sorted_hits = torch.topk(match_scores, k=top_count).indices.cpu().numpy()
    
    print(f"Query Parsed: '{search_string}'\n")
    print("Top System Matches:")
    for rank, offset in enumerate(sorted_hits, 1):
        print(f"{rank}. {mock_items[offset]} (Score: {match_scores[offset].item():.2f})")

# Verify semantic retrieval link
query_by_text("blue casual shirt")
